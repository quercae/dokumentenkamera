# dokumentenkamera
pysideQt Anwendung für USB Dokumentenkameras, speziell für das graue 16 MP Modell von Gtremulent.

Bedienung mithilfe von Tastatur, Maus oder Buttons möglich. Wenn im Kamerabild mit der Maus eine Rechteckauswahl vorgenommen wird, wird der Bildausschnitt in nativer Kameraauflösung automatisch in die Zwischenablage kopiert.

Der Speichern Button speichert die ausgewählte Kamera und Auflösung in einer Einstellungsdatei.

install.sh automatisiert die Installation von fehlenden Paketen unter Kubuntu und fügt einen Eintrag im Startmenü hinzu.
